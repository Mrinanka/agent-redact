## Managed-mode simulation recipe

Windows 11 Home has no Windows Sandbox or Hyper-V, so a temporary file on the owner's PC was used (D-020).

1. `node experiments/step0-mock/manual.ts managed-file <out.json>` writes the file: `allowManagedHooksOnly: true` plus the step 0 settings hook as managed hooks (`--source managed`) on `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`. It is checked to parse as JSON (an unparseable managed file stops Claude Code from starting).
2. As admin: create `C:\Program Files\ClaudeCode\` and copy the file in as `managed-settings.json`.
3. Run the scenarios `control`, `command`, `safe-mode`, `kill-project` (`node experiments/step0-mock/run.ts ...`).
4. As admin: delete the folder. Confirm it is gone.

Observed (2026-10-31, 2.1.316): see rows 0.7, 0.8 and 0.14. The file applies to every session on the machine while it exists, including the one running the test, so keep the window short.

## The probe (part 0.A)

`experiments/step0-probe/` is a mod that writes one JSON line per `session.append` row: door, type, name, role, isMeta, origin (kind plus tool, model, event or name), uuid, agentId, and each block's type and size. It never writes content. It is the evidence source for 0.1, 0.5, 0.10 and later checks. See its `README.md`.

- **Load:** run `claude --plugin-dir "<repo>/experiments/step0-probe"` from a scratch folder (add `-p "<prompt>"` for headless).
- **Log:** `<cwd>/.step0-probe/<session id>.jsonl`. A `start` line (probe version, engine version, surface, interactive) is written per load, then one `row` line per row.
- **Evidence for a row:** quote the log lines or a tally (for example, the count per door). Lines hold sizes and ids only, so they can be pasted as they are.
- **Re-check:** rerun the same scenario with the new `claude --version` and compare the tallies.
- **Self-test:** `claude plugin test ./experiments/step0-probe` (22 tests, including "a planted fake appears in no write").
- **Opt-in checks:** each is off unless `<cwd>/.step0-probe/on-<name>` exists: `mention` (0.2), `resume` and `resume-hold` (0.3), `runtime` (0.4, 0.13), `media` (0.5), `budget` (0.6), `hide` (0.10), `store` (0.4). The command `/step0-probe:step0-status` is a plain markdown command (0.7).
- **Headless runs:** `node experiments/step0-mock/run.ts <scenario|all>` runs a scenario against the local mock with its own `CLAUDE_CONFIG_DIR` and prints a summary of labels and flags (canaries never printed). Hand-run checks: `node experiments/step0-mock/manual.ts setup <dir> [markers]`.
