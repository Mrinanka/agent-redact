# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its text is not copied here, so the link is always the current wording.

In short: be kind, assume good faith, and keep the discussion about the work. Harassment of any kind is not accepted.

To report a conduct problem, use GitHub's "Report content" on the comment or issue, or open a private security advisory on this repository (<https://github.com/Mrinanka/aegiscontext/security/advisories/new>) and say that it is a conduct report. The maintainer reads reports privately and acts on them at their discretion.
